# **App Name**: FemiTech Survey

## Core Features:

- Dynamic Form Generation: Generate a fully responsive single-column web form using Ant Design components, based on the provided survey questions and options.
- Field Validation: Implement field validation for mandatory questions to ensure complete responses.
- Submission Handling: Configure the form to send data to a specified endpoint (Formspree, Formcarry, or dummy POST endpoint).
- Success Messaging: Display a success message upon form submission: '💜 ¡Gracias por sumar tu voz! Tus respuestas nos ayudan a pensar juntas soluciones digitales para nuestra comunidad.'
- AI-Powered Suggestion Tool: Based on the answers from questions 2, 3 and 4, suggest resources for a business relevant to the respondent's interests.  AI will reason to incorporate responses from questions 1, 5, 6 and 7, as extra background, and optionally include them as constraints, to tailor the response.

## Style Guidelines:

- Primary color: Vibrant violet (#9400D3), drawing from feminist color themes to represent empowerment and vision.
- Background color: Very light desaturated violet (#F0E6F7), providing a soft and visually calming backdrop.
- Accent color: Soft rose (#D81B60) to highlight key interactions and enhance the energetic feel, standing out distinctly against the primary and background.
- Font: 'Poppins', a geometric sans-serif font known for its clarity and rounded forms, providing good legibility and a friendly feel.
- Single-column layout for responsiveness, ensuring optimal viewing experience across devices. Generous spacing to enhance readability.
- Smooth entrance animations for each section using framer-motion or CSS animations, adding a dynamic feel. Animated hover states on buttons.
